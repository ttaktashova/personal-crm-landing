# Черный список — лендинг

Одностраничный лендинг личной CRM. Все кнопки ведут в приложение: https://app.testblacklist.site

## Как запустить у себя

Нужны Node.js 22+ и pnpm.

```
pnpm install     # поставить зависимости
pnpm dev         # страница с автообновлением: http://localhost:4321
pnpm build       # собрать готовый сайт в папку dist/
pnpm preview     # открыть собранный сайт: http://localhost:4321
```

## Где что лежит

- `src/config.ts` — адрес приложения для кнопок
- `src/styles/tokens.css` — цвета, шрифты, размеры, отступы
- `src/components/sections/` — блоки страницы по порядку: шапка, первый экран, «Знакомо?», «Можешь больше не переживать», «Зашел — увидел — отомстил», красный блок, подвал
- `design/` — макет, с которым сверялась вёрстка
