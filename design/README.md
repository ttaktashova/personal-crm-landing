# Макет лендинга «Черный список»

Материалы для вёрстки лендинга на Astro + Tailwind CSS 4. Источник правды по стеку и правилам — `CLAUDE.md` в корне проекта. Этот файл — про вид страницы: токены, блоки, тексты, адаптив, доступность.

Исходный макет — холст «Черный список — первый экран» (артборды «E · Весь лендинг» и «E · Десктоп»): https://claude.ai/artifact/2aSWjp49M6kXDkajCTqvrC — ссылка приватная, открывается только у владельца.

## 1. Обзор

Одна статичная страница, одно целевое действие — **перейти в приложение**. Все кнопки ведут на один адрес `APP_URL` (`https://app.<домен>`, см. `CLAUDE.md`). Других ссылок, форм и пунктов меню на странице нет: всё, что не ведёт в приложение, отвлекает от единственного действия.

Порядок блоков (одинаковый на телефоне и компьютере):

1. Шапка
2. Первый экран — «Черный список — запомни всех!»
3. Проблема — «Знакомо?»
4. Решение — «Можешь больше не переживать»
5. Выгоды — «Зашел — увидел — отомстил»
6. Финальный призыв — красный блок
7. Подвал

Тема одна, тёмная. Светлой версии нет.

## 2. Сетка и адаптив

| Ширина экрана | Раскладка | Образец |
|---------------|-----------|---------|
| 320–639 px | Одна колонка на всю ширину, поля 24 px (`px-6`) | `mobile.html` |
| 640–1023 px | Та же одна колонка, по центру, не шире `max-w-xl` (576 px). Фон — на всю ширину | `mobile.html` |
| ≥ 1024 px (`lg`) | Две колонки, контейнер `max-w-7xl` (1280 px) по центру, поля 40 px (`lg:px-10`) | `desktop.html` |
| > 1440 px | Как 1440: контейнер не растёт, фон и разделители на всю ширину | `desktop.html` |

Брейкпоинт один — стандартный `lg` из Tailwind. На планшете оставляем мобильную раскладку: двухколоночные блоки уже 1024 px ломаются, а мобильная колонка 576 px держит пропорции иллюстраций.

Двухколоночные блоки на `lg` верстаются CSS-гридом:

| Блок | Колонки на `lg` | Выравнивание |
|------|-----------------|--------------|
| Первый экран | `grid-cols-2`, зазор 64 px (`gap-16`) | по центру по вертикали |
| Проблема | `grid-cols-[1fr_2fr]`, `gap-16` | по центру |
| Решение | `grid-cols-2`, `gap-16` | текст по центру, телефон прижат к низу блока |
| Выгоды | `grid-cols-[1fr_2fr]`, `gap-16` | по верху |
| Финальный блок | `grid-cols-[auto_1fr]`, зазор 56 px (`gap-14`) | кот прижат к низу, текст по центру |

Высоты секций не фиксировать и не растягивать на `100svh`. На экране шириной 393 px первый экран сам получается высотой около 844 px. Иллюстрации и плашки привязаны к своему блоку в процентах (см. 6.2), и принудительная высота их разъедет.

## 4. Шрифты

| Шрифт | Начертания | Где |
|-------|------------|-----|
| Dela Gothic One | 400 | Заголовки, лента, кнопки, логотип, номера плашек, «?» |

Нужна кириллица. В макете шрифты подключены ссылкой на Google Fonts с `display=swap`:

```
https://fonts.googleapis.com/css2?family=Caveat:wght@600&family=Dela+Gothic+One&family=Golos+Text:wght@400;500;600&display=swap
```

Хранить шрифты у себя (например, через пакеты Fontsource) быстрее и не зависит от Google, но это новая библиотека — по `CLAUDE.md` сначала согласовать с владельцем (см. «Открытые вопросы»).

## 5. Структура страницы и компоненты

```
<body>
  <header>                       шапка
  <main>
    <section aria-labelledby>    первый экран (h1)
    <section aria-labelledby>    проблема (h2)
```

Секции 3–5 и подвал отделены сверху линией 1 px цвета `line` на всю ширину экрана.

Предлагаемые компоненты Astro (имена файлов на английском):

| Компонент | Варианты / пропсы | Заметки |

## 6. Блоки

Размеры даны как «телефон → компьютер». Точные пиксели любого элемента — в инлайн-стилях `mobile.html` / `desktop.html`.

### 6.1 Шапка

| | Телефон | Компьютер |
|--|---------|-----------|
| Отступы | сверху 20 px, по бокам 24 px, высота строки 44 px | 24 px сверху и снизу, по бокам 40 px |
| Слева | логотип 32 px + «черный список» (display 15 px), зазор 10 | логотип 36 px + надпись 18 px, зазор 12; рядом плашка «личная CRM» с зазором 16 |
| Справа | плашка «личная CRM»: рамка 1 px `border-strong`, `rounded-full`, поля 6/12, цвет `text-pill` | кнопка `CtaButton size="sm"`: высота 44, поля 20, `rounded-xl`, без тени |

Шапка не липкая. На телефоне кнопки в шапке нет: кнопка первого экрана видна сразу.

### 6.2 Первый экран

**Телефон.** Одна колонка, по порядку:

1. h1 «Черный / список —», две строки, отступ сверху 22 px.
2. Лента «запомни всех!»: фон `accent`, текст `ink`, поля 8/16/10, поворот −3°, ширина по тексту, отступ сверху 12 px. Лента — часть h1 (см. «Доступность»).
3. Подзаголовок, отступ 18 px, ширина не больше 290 px, цвет `text-muted`.
4. Иллюстрация на всю ширину экрана (поля −24 px), пропорция 393 : 387.
5. Кнопка `CtaButton variant="accent" size="md" block`: высота 60, `rounded-2xl`, `shadow-cta`, отступ сверху 16.
6. Подпись «С любого устройства — в любое время», по центру, `text-faint`, отступ 14. Снизу у блока 28 px.

**Компьютер.** Две колонки. Слева текст: h1 → лента (отступ 20, поля 10/22/12) → подзаголовок (отступ 32, шире не больше 460) → кнопка `size="lg"`, по ширине текста (высота 64, поля 32, `shadow-cta-lg`, отступ 36) → подпись (отступ 18). Справа иллюстрация: не шире 560 px, пропорция 560 : 600, по центру колонки. Отступы блока: сверху 40, снизу `clamp(72px, 8vw, 104px)`.

**Иллюстрация** — блок с `position: relative` и заданной пропорцией. Все детали внутри — `absolute`, координаты в процентах от блока, поэтому сцена масштабируется целиком. Порядок слоёв снизу вверх: диск → стрелка → кот → плашки → подпись.

| Плашка #03 «Начальник» | right 3.05 %, top 25.84 %, поворот −3° | right 1 %, top 29 %, поворот −3° |

### 6.3 Проблема — «Знакомо?»

| | Телефон | Компьютер |
|--|---------|-----------|
| Отступы блока | 72 сверху, 64 снизу, по бокам 24 | `py-section-lg`, по бокам 40 |
| Заголовок | строка: h2 слева, кот `cat-confused` 130×92 справа, по нижнему краю; под строкой 12 px | левая колонка: кот 180×128 над h2, зазор 20 |
| Карточки | две, друг под другом, зазор 12 | правая колонка, друг под другом, зазор 16 |
| Карточка | фон `surface`, рамка `border`, `rounded-card`, поля 20, иконка и текст по верху, зазор 16 | `rounded-3xl`, поля 28, иконка и текст по центру, зазор 20 |
| Плитка иконки | 44×44, `rounded-xl`, фон `accent`, иконка `ink` | 52×52, `rounded-chip` |

### 6.4 Решение — «Можешь больше не переживать»

## 8. Состояния и взаимодействия

Интерактивны только кнопки «Перейти в приложение». Всё остальное — картинка и текст: без наведения, без кликов.

| Элемент | Состояние | Поведение |
|---------|-----------|-----------|
| Красная кнопка с тенью (первый экран) | обычное | фон `accent`, текст `ink`, тень `shadow-cta` / `shadow-cta-lg` |
| | наведение | сдвиг на −2 px по обеим осям, тень `shadow-cta-hover` / `shadow-cta-lg-hover` |
| | нажатие | сдвиг на +4 px (+5 на `lg`) по обеим осям, тень 0 — кнопка «вдавливается» в свою тень |
| | фокус с клавиатуры | обводка 3 px `cream`, отступ 3 px (`focus-visible`) |
| Тёмная кнопка (финальный блок) | наведение / нажатие | как у красной, тень `cream` |

Переходы: `transform`, `box-shadow`, `background-color` — 150 мс, `ease-out`. При `prefers-reduced-motion: reduce` сдвигов нет, меняются только тень и цвет. Состояний загрузки, ошибок и пустых данных у страницы нет: она статичная.

## 10. Доступность

- `<html lang="ru">`. Один `h1`, внутри — весь заголовок: «Черный список —» и лента «запомни всех!» как `<span>`. Так экранный диктор читает фразу целиком. Каждая секция с `h2` связана с ним через `aria-labelledby`. У финального блока нет `h2` — его `aria-labelledby` указывает на абзац «Устанавливай прямо сейчас…».
- Порядок фокуса: кнопка в шапке (только на `lg`) → кнопка первого экрана → кнопка финального блока. Других фокусируемых элементов нет. Логотип — не ссылка.
- Кнопки — настоящие `<a href>`. Стрелка в кнопке — `aria-hidden="true"`.
- Иллюстрации с котами — `role="img"` и `aria-label` (тексты уже в SVG-файлах). Кот с «?», диски, стрелки, иконки в плитках и плашках — `aria-hidden="true"`.
- Плашки #01–#03 — список `<ul aria-label="Примеры записей">`, порядок чтения — по номерам.
- Телефон с экраном — одна картинка: `role="img" aria-label="Экран приложения: список людей и за что они в нём"`, содержимое внутри скрыто от диктора. Это иллюстрация, а не интерфейс.
- Зачёркнутая цитата — тег `<s>`. Смысл не теряется: перед ней стоит «Больше никаких».
- Контраст проверен по WCAG AA (≥ 4.5 : 1 для обычного текста):

| Пара | Контраст |
|------|----------|
| `cream` на `ink` | 16.3 |
| `accent` на `ink` / `ink` на `accent` | 5.6 |
| `text-muted` на `ink` | 10.3 |
| `text-faint` на `ink` | 6.6 |
| `text-footer` на `ink` | 5.0 |
| `text-body` на `surface` | 12.7 |
| `text-subtle` на `surface` | 7.5 |
| `accent` на `surface` (значок, номера) | 5.1 |
| `on-accent-muted` на `accent` | 4.9 |
| `screen-muted` на `cream` / на `screen-field` | 5.5 / 4.8 |

- Кнопки не ниже 44 px (60–64 в блоках, 44 в шапке).
- Масштаб текста до 200 % не должен ломать страницу: тексты переносятся, блоки растут вниз.

## 11. Крайние случаи

- **Узкий экран 320–359 px.** Размеры h1, ленты и заголовка «Решения» заданы через `clamp`, чтобы самое длинное слово влезало. Сцена с телефоном (393 px) шире экрана: она центрируется, края красного диска срезаются — это допустимо. Плашки первого экрана на 320 px могут сильнее наезжать на кота — допустимо, но они не должны выходить за край экрана.
- **Шрифты ещё не загрузились.** `font-display: swap`. Запасной шрифт для Dela Gothic One — Golos Text / system-ui: он уже, строки заголовков не переполнятся. Строки заголовков разбиты блочными `<span>`, а не `<br>`, поэтому разбиение одинаковое до и после загрузки.
- **Медленная сеть.** Картинок нет — все иллюстрации в инлайн-SVG, грузится только HTML, CSS и шрифты.
- **Без JavaScript.** Страница полностью работает: JS не нужен вообще.
- **Очень широкий экран.** Контейнер 1280 px по центру, фон и линии секций на всю ширину.
- **Другие тексты.** Если владелец поменяет текст плашек или строк телефона: причина в плашке — до ~24 символов, в строке телефона — до ~22, иначе перенос на вторую строку. Карточки по высоте растут сами.

## 12. Открытые вопросы — решает владелец

1. **Домен приложения** для `APP_URL` (`https://app.<домен>`).
2. **Шрифты:** оставить Google Fonts, как в макете, или хранить у себя (новая библиотека — нужно согласие).
3. **Мета-теги и картинка для соцсетей.** Предложение: `<title>` — «Черный список — запомни всех!», description — «Храни в одном месте всех, кто тебя раздражает» (оба текста из макета). Картинки для соцсетей в макете нет.
4. **Фавиконка:** предлагается `assets/logo.svg`.
5. **Подвал:** нужны ли год, юридическая информация, контакты. В макете только логотип и «личная CRM».

## 13. Как проверить готовую страницу

- Сравнить с `mobile.html` на ширине 393 px и с `desktop.html` на 1440 px: порядок блоков, тексты, цвета, отступы, положение котов и плашек.
- Проверить ширины 320, 768, 1024 и 1920 px: нет горизонтальной прокрутки, ничего не обрезано, кроме задуманного (низ телефона, края диска на 320).
- Пройти страницу клавишей Tab: фокус виден на всех кнопках, порядок как в разделе 10.
- Все кнопки ведут на `APP_URL`.
- Скриншоты на телефоне и компьютере — владельцу (`CLAUDE.md`).
